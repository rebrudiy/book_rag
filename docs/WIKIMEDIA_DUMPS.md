# Русский Викиучебник: потоковый каталог и пакеты проверки

`book_rag.wikimedia_dump` скачивает один явно разрешённый снимок, проверяет его и
строит отдельный офлайн-каталог страниц и предполагаемых связей глав. Он **не
импортирует книги в поисковую библиотеку**. Подстраницы, редиректы и корни не
считаются подтверждёнными полными уникальными произведениями.

## Источник и права

Использован [официальный current-снимок от 2026-11-01](https://dumps.wikimedia.org/other/mediawiki_content_current/ruwikibooks/2026-11-01/xml/bzip2/):

- `ruwikibooks-2026-11-01-p1p35928.xml.bz2` — **25 354 533 байта**;
- SHA-256 из [официального SHA256SUMS](https://dumps.wikimedia.org/other/mediawiki_content_current/ruwikibooks/2026-11-01/xml/bzip2/SHA256SUMS):
  `b16b4e932e6b24637f557592229ce40bdfe16c70ef9f4afd794e5ad3d8a052e7`;
- полный URL закреплён в `WIKIBOOKS_SPEC`, изменяемый `latest` не используется.

[Политика Викиучебника](https://ru.wikibooks.org/wiki/Викиучебник:Авторские_права)
допускает повторное использование свободных текстовых вкладов с атрибуцией и
сохранением лицензии. [Условия выгрузок Wikimedia](https://dumps.wikimedia.org/legal.html)
указывают CC BY-SA 4.0 для обычного текстового содержимого и предупреждают об
исключениях; изображения имеют отдельные условия. Поэтому общая лицензия сайта
не служит проверкой прав на любую заимствованную книгу, перевод или иллюстрацию.

Для каждой страницы сохранены исходный title, page ID, revision ID, timestamp,
SHA1 поставщика, собственный SHA-256 wikitext и URL страницы, точной ревизии и
истории вкладов. Пакеты содержат CC BY-SA credit и ссылки на правила. История всех
соавторов **не включена** в current-снимок; её не подменяет автор последней правки.
Перед распространением производной книги нужна проверка исключений и пригодной
атрибуции по её страницам. Имена авторов произведения загрузчик не угадывает.

Формат — **bzip2 XML**, не gzip. [Официальное описание экспорта](https://wikitech.wikimedia.org/wiki/MediaWiki_Content_File_Exports)
объясняет, что current содержит актуальные ревизии в исходной вики-разметке.
Готовность файла экспорта не доказывает завершённость учебников внутри него.

## Запуск и контракт

Из корня проекта, без новых зависимостей:

```python
from pathlib import Path
from book_rag.wikimedia_dump import (
    acquire_wikibooks_dump,
    build_wikimedia_catalog,
    export_wikimedia_review_packet,
)

base = Path("data/wikimedia/ruwikibooks-2026-11-01")
artifact = acquire_wikibooks_dump(base)
report = build_wikimedia_catalog(artifact["path"], base / "catalog")
packet = export_wikimedia_review_packet(Path(report["catalog"]), "Регулярные выражения", base / "review-packets")
```

Публичные функции:

- `acquire_wikibooks_dump(destination: Path) -> dict`: возвращает `path`, `bytes`,
  `sha256`, `cached`, `network_requests`. Скачивает только закреплённый файл.
- `build_wikimedia_catalog(dump_path, output_dir, candidate_titles=None, *,
  spec=None) -> dict`: возвращает и атомарно сохраняет `catalog-report.json`;
  отдельная SQLite находится в поле `catalog`. По умолчанию проверяет 12
  согласованных кандидатов. `spec` предназначен для явного закрепления другого
  локального официального current-файла и небольших тестовых фикстур; URL
  произвольных провайдеров не принимается. Сама функция HTTP не выполняет.
- `export_wikimedia_review_packet(catalog, title, destination) -> dict`: читает
  каталог SQLite с `mode=ro`, публикует файлы `page-ID-revision-ID.wikitext` и
  `review-packet.json`, возвращает путь пакета, статус, число страниц и байтов.
  Это **не манифест источников Library**; импорт не вызывается.

Файлы под `data/` игнорируются Git. Схема SQLite содержит `metadata`, `pages`,
`links`, `templates`, `page_issues`. Полный текст сохраняется только для
namespace 0; служебные пространства имеют метаданные. Текст — точный UTF-8
результат декодирования XML `<text>`: сущности XML декодированы, стандартная
нормализация переводов строк XML уже выполнена парсером. Wikitext, отступы,
пробелы кода, математическая разметка и исходное оглавление не переписываются.
Только поисковые ключи заголовков получают NFC, пробельную нормализацию и замену
подчёркивания пробелом; исходный title хранится отдельно.

## Ограничения ресурсов и восстановление

Размер и SHA проверяются до XML-разбора, включая повторный запуск. Корректный
кэш означает ноль HTTP-запросов. Загрузка идёт атомарно в `.part`, без HTTP
редиректов и скрытого retry-loop; при 403/429/503 полный `Retry-After` сохраняется
в `acquisition.json`, повторный запрос до его истечения запрещён. Повреждённое
состояние отсрочки не обходит ограничение провайдера.

Сжатый лимит — 30 МиБ; распакованный XML ограничен **256 МиБ до передачи парсеру**.
Декодер выдаёт блоки не больше 64 КиБ и отвергает усечённый поток, приписанные
данные и второй bzip2 stream. `defusedxml` запрещает DTD, сущности и внешние
ресурсы. Обработанные XML-страницы удаляются из дерева; весь dump не
распаковывается в память или временный XML-файл. Есть пределы 100 000 страниц и
4 МиБ UTF-8 на одну страницу.

Каталог строится в `catalog.sqlite3.building`; ошибочный проход не заменяет
предыдущий опубликованный каталог. После прерывания небольшой архив разбирается
заново, а не скачивается повторно. Публикация отдельных файлов атомарна; отчёт и
SQLite не образуют общей файловой транзакции, поэтому при прерывании между их
публикациями нужно повторить построение. Одновременные сборки в одну директорию
не поддерживаются.

Извлечение ссылок и шаблонов намеренно ограничено: до 10 000 ссылок / 2 000
шаблонов на страницу, глубина шаблонов 32. Превышение оставляет исходный текст и
ставит явную проблему метаданных, блокирующую замкнутость графа. Семейство больше
2 000 страниц, граф больше 50 000 записей или отчёт больше 25 кандидатов требуют
отдельного прохода. Это анализатор метаданных, не движок MediaWiki: сложная
разметка может давать консервативные предупреждения.

Пути: `review-packets/ruwikibooks-page-5267/`, `...-21820/`, `...-14032/` внутри
runtime-директории снимка. Каждый пакет сохраняет полный root/TOC и все имеющиеся
исходные страницы своего семейства, включая недостижимые; отсутствующая глава не
подменяется пустым текстом. Статусы `coverage=unverified`,
`identity_status=provisional_family_not_verified_unique_work`,
`rendering_status=raw_wikitext_only`, `full_book_claimed=false` сохраняются даже
при замкнутом графе. Семейство по префиксу title — область проверки, а не
авторитетное оглавление произведения; ссылки на другие семейства сохранены
отдельно для ручной классификации «глава или справочная ссылка».

Точная следующая задача: начать с одностраничных «Регулярных выражений» —
проверить историю/права и создать воспроизводимый ограниченный рендерер с

Library-манифест с честной областью покрытия. Массовое повышение корней до
«полных книг» этим этапом не разрешается.
