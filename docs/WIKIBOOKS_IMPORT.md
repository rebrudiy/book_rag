# Закреплённый импорт «Регулярных выражений»

`book_rag.wikibooks_sources.acquire_wikibooks_regex(destination: Path) -> dict`
подготавливает один современный коллективный учебный справочник из русского
Викиучебника. Загрузчик не обходит сайт, не меняет Library/SQLite и не подключает
платные сервисы. Он публикует обычный локальный манифест только после проверки
прав, идентичности источника и сохранности текста существующим книжным парсером.

Источник: [страница ревизии 266423](https://ru.wikibooks.org/w/index.php?oldid=266423),
page ID 5267, «Регулярные выражения». SHA-256 исходного wikitext:
`0a8ef5106a6ee30553406e864c4269000bb561a1df805913aeb001160ef5413a`.
Этот SHA совпал у API и ранее проверенного офлайн-дампа. Другие книги, архивы и
ссылки из библиографии не скачиваются.

## Права и атрибуция

API `siteinfo/rightsinfo` явно вернул CC BY-SA 4.0. Условия
[Викиучебника](https://ru.wikibooks.org/wiki/Викиучебник:Авторские_права) и
[Wikimedia Terms of Use, раздел 7](https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use#7._Licensing_of_Content)
разрешают повторное использование текстовых вкладов с атрибуцией и сохранением
лицензии; ссылка на страницу и её историю служит предусмотренным способом
атрибуции участников. Сохраняются также
[полный текст CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/legalcode.en),
официальные правила проекта и Terms of Use, каждый с URL, временем и SHA ответа.

Проверены закреплённое содержимое, текущая страница обсуждения (ревизия 106231)
и первые 50 записей истории. Явных запретов или утверждения о копировании
несвободной печатной книги в них не обнаружено. Перечисленная библиография
сохраняется как ссылки на источники, без переноса лицензии Викиучебника на книги
этих издательств. Это ограниченная проверка, не аудит каждой правки за все годы.

Найдено конкретное свидетельство происхождения: первая
[правка 25968](https://ru.wikibooks.org/w/index.php?oldid=25968) прямо указывает
начало работы на основе статьи русской Википедии. Поэтому credits включают
участников **обоих** проектов, [исходную статью](https://ru.wikipedia.org/wiki/Регулярные_выражения)
и её историю. Правка 60681 сообщает о дополнении из английской версии без точного
URL; комментарий и номер сохранены в `uncertain_upstream_notes`. Переводчик и
конкретное английское издание не угадываются. Полный список всех участников не
выводится из имени автора последней правки: используются ссылки на истории.

Изображения не загружаются и не распространяются, поскольку их лицензирование
отдельно; текстовые подписи сохранены. Производный текст FB2 остаётся CC BY-SA
4.0, преобразования и Book RAG credit явно указаны в первой редакторской секции.
Эта секция имеет отдельное правило атрибуции с SHA артефакта и текстовым guard.

## Что именно закреплено

Сохранён ответ [официального `action=parse`](https://www.mediawiki.org/wiki/API:Parsing_wikitext)
для **`oldid=266423`**, включая HTML, wikitext, номера/заголовки разделов,
использованные шаблоны и предупреждения. Проверяются точные page ID, title,
revision ID и SHA wikitext. Чужая ревизия или parser warnings блокируют выпуск.

Старый текст может рендериться с **текущими версиями шаблонов**. Поэтому
производный FB2 закреплён к сохранённому HTML-ответу, его SHA и времени получения,
а не объявлен полностью воспроизводимым только из исторического wikitext.
Полный ответ API, полученный HTML-фрагмент, исходная разметка, request/response
SHA и карта преобразования остаются в пакете происхождения. SHA ответов относятся
к HTTP entity после распаковки транспортного gzip, что записано в receipts.

Подтверждённый конкретный дефект исходного рендера: в одном многострочном
регулярном выражении обычные пробелы были заменены на NBSP. Проекция восстанавливает
**все 27** `<source>`-блоков буквально из закреплённого wikitext, включая краевые
LF, табуляцию и внутренние пробелы. Для каждого блока сохранены исходные offsets,
SHA исходного и отрендеренного текста и описание восстановления.

Из 333 встроенных `<code>` 327 напрямую сверены с исходными литералами после
декодирования сущностей и снятия оболочки `nowiki`. Ещё 6 содержат шаблоны:
сохраняется их официальный закреплённый рендер, без удаления шаблонов или
придумывания раскрытия. Переводы строк `<br>` внутри кода сохраняются.

Каждый значимый текстовый узел HTML основного содержимого должен быть потреблён
**ровно один раз**. Это проверяет сохранность абзацев, определений, списков,
подписей и содержимого шаблонов. Удаляются только script/style/link/meta, картинки
и кнопки редактирования. Все 24 исходных заголовка сверены с inventory API и
после FB2-разбора; соседние заголовки без текста объединяются в составной title.

Таблицы сохраняют строки, содержимое ячеек, заголовки и `colspan` в карте
происхождения. В читателе это текстовая проекция: LF между строками, TAB между
ячейками, дополнительные пустые ячейки для `colspan`. Внутренние LF и код в ячейке
сохраняются. Это не факсимиле HTML-таблиц. Встреча `rowspan`, вложенной таблицы
или математического рендера блокирует этот ограниченный конвертер; на данной
странице их нет. Элементов математических формул и сносок `ref` также нет —
проверка не заявляет испытанную поддержку отсутствующих здесь конструкций.

Текстовые блоки FB2 используют `code xml:space="preserve"` как носитель буквального
текста, в том числе для абзацев с regex. Это предотвращает схлопывание пробелов
существующим парсером; не означает, что весь абзац является программой.

## Повторение и импорт

```python
from pathlib import Path
from book_rag.wikibooks_sources import acquire_wikibooks_regex

result = acquire_wikibooks_regex(Path("data/wikimedia/wikibooks-regex-266423"))
print(result["manifest"])
```

Запросы выполняются последовательно с интервалом не меньше 3 секунд,
описательным User-Agent, gzip и `maxlag=5`. На один ответ действует предел 5 МиБ.
Интервал сохраняется между запусками; проверенные cache hits не требуют паузы.
403/429/5xx и API `maxlag/ratelimited/readonly` сохраняют отсрочку хоста, без
повторного запроса в этом запуске. Полный `Retry-After` не сокращается. Ответы и
производные файлы публикуются атомарно; повреждённый кэш проверяется по размеру и
SHA. Манифест публикуется последним, после round-trip проверки всех блоков,
заголовков и inline code существующим парсером.

Готовый `manifest.json` можно передать существующему локальному ingest. Загрузчик
не выполняет этот шаг самостоятельно. При объединении очередей сохранять
текущие записи по `id`, добавить `ruwikibooks-regex-266423` один раз и не заменять
существующие curated work IDs значением этого provisional source-page ID.
